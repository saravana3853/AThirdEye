### Eye for Blind

1. A notebook to create an Image2Text model based on flicker dataset
2. A notebook to host streamlit ui where an image can be uploaded and the caption is read as audio
3. h5 files for Model Weights 
4. A pkl file for Extracted Features
5. A pkl file for tokenized word index
6. Requirements and Docker Files
7. A resultant mp3 file

### To Create the Model

an-eye-for-blind.ipynb - Run the notebook . The notebook produces
    1. caption_decode.weights.h5 - Only Weights
    2. model.h5 - Full Model
    3. flicker_feature_cache.pkl - Extracted Feature from Vision Transformer
    4. tokenizer.pkl - Keras Tokenizer Stored to be used by decoder for Generating caption


### To Use The created Model

1. Using the notebook - eye-for-blind-ui.ipynb
    1. Configure the path of caption_decode.weights.h5 in the notebook
    2. Configure  the path of tokenizer.pkl file in the notebook
    3. Run the notebook
    4. The public url would be generated by ngrok
    5. Visit the site and see the app loading
2. Using the Docker
    1. Clone the repo      
    2. docker build -t image-caption-app .
    3. docker run -p 8501:8501 image-caption-app
    4. visit localhost:8501 and see the app loading
    
### DataSet :  

/kaggle/input/flickr-image-dataset

### Architecture:

1. Vision Transformer Feature Extractor 
2. Vision Transformer Model for patch embedding
3. Feature Cache to pkl
4. Custom Decoder (with LSTM and Attention Transformers)
5. Inference via Greedy Search
6. Inference via Beam Search
7. Visualizing Attention Weights
8. Bleu Score Eval
9. Model Weights Saved
10. Convert Caption to mp3 using gtts
